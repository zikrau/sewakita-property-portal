# SewaKita — Versi Gratis vs Berbayar

## Versi Gratis — cocok untuk mulai

Target: validasi ide, tugas, komunitas lokal, dan jumlah listing awal.

Stack:

- GitHub Free untuk source code.
- Vercel Hobby untuk deployment awal.
- Supabase Free untuk database, Auth, dan Storage.
- Domain bawaan platform untuk testing.

Fitur aplikasi:

- Beranda elegan.
- Pencarian/filter.
- Detail properti.
- Registrasi/login.
- Dashboard pemilik.
- Tambah/edit properti.
- Upload foto.
- Moderasi.
- Verifikasi.
- Featured.
- Laporan listing.
- Audit log.
- SEO sitemap/robots.

## Versi Berbayar — untuk operasional serius

Naikkan layanan ketika penggunaan sudah membutuhkan kapasitas, performa, backup, dan domain bisnis.

Tambahkan:

- Domain resmi.
- Hosting plan yang mendukung kebutuhan traffic.
- Database/storage plan yang lebih besar.
- Backup produksi yang sesuai kebutuhan.
- Rate limiting.
- CAPTCHA/anti-spam.
- Monitoring/error tracking.
- Analytics.
- Email transaksional.
- WhatsApp bisnis/CRM bila diperlukan.
- CDN/WAF/aturan keamanan tambahan sesuai provider.

## Monetisasi SewaKita

Aplikasi dapat dibuat gratis untuk pencari properti, sementara pemilik/agen membayar fitur promosi.

### Paket Pemilik Gratis

- Listing terbatas.
- Moderasi standar.
- Kontak WhatsApp.

### Paket Pemilik Premium

Contoh harga dapat ditentukan kemudian, misalnya Rp29.000–Rp49.000/bulan.

- Listing lebih banyak.
- Featured listing.
- Prioritas penayangan.
- Statistik kunjungan.
- Statistik klik WhatsApp.
- Badge bisnis/premium.

### Paket Agen

Contoh harga dapat ditentukan kemudian, misalnya Rp99.000–Rp199.000/bulan.

- Banyak listing.
- Profil agen.
- Manajemen tim.
- Statistik.
- Promosi.

Pembayaran online belum diaktifkan dalam paket starter ini. Untuk tahap berikutnya dapat ditambahkan payment gateway Indonesia setelah model bisnis diputuskan.
